# AASE demonstration

1. Enable **Use demo data** in the Streamlit app.
2. Upload `demo/academic_calendar.csv` with demo mode disabled, or use the CSV as a reference for the calendar schema.
3. Test **Calendar impact analysis** to see which recurring weekday slots lose teaching occurrences.
4. Test **Disruption simulator** with a teacher or room failure.
5. Run **Robustness analysis** to stress-test the timetable.

The demo calendar is synthetic and exists only to demonstrate the parser and scheduling workflow.
